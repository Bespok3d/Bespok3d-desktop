# AGENTS

The agent instructions for the Bespok3d desktop app live in [CLAUDE.md](CLAUDE.md): the app-specific
engineering rules (eslint/gate specifics), the resilience and CSS patterns, the working procedure, and
the hard constraints every AI-assisted change to this repo must follow. Read it before making
changes, whichever tool you are. When this repo is checked out inside the Bespok3d workspace, the
workspace-root `CLAUDE.md` (the universal rules) applies on top of it.
